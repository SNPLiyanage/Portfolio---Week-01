University Project

ARTIFICIAL INTELLIGENCE · AUDIO CLASSIFICATION

Fault Detection Software Using Audio Classification

As part of my university project, I worked on a fault detection system that uses audio signals from an air compressor to identify different machine conditions.

The project involved extracting audio features from recorded signals and using machine learning classification models to distinguish between healthy and faulty operating conditions.

The system was developed as an interactive MATLAB application. Users can upload an audio file, extract relevant features, view the frequency spectrum and classify the detected fault using the trained model.

Audio Processing

Machine Learning
